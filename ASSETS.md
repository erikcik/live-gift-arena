# Assets

Everything in the scene and the demo soundtrack is generated by code in this repo:

- **Characters, village, lights, fireworks**: built from Three.js primitives in `scene/src/` (no model files).
- **Textures**: the ground and stone square are drawn on a canvas at runtime (`scene/src/world.js`).
- **Music and effects**: synthesised in `tools/audio/synth.py` (davul, zurna in Hicaz, claps, bells, fireworks). No samples.
- **Fonts and emoji**: the viewer's system fonts. Nothing is bundled.
- **TikTok gift images**: not included. Gifts are shown as emoji.

Third-party code: [three.js](https://github.com/mrdoob/three.js) (MIT), [Vite](https://github.com/vitejs/vite) (MIT),
[playwright-core](https://github.com/microsoft/playwright) (Apache-2.0, demo rendering only).
